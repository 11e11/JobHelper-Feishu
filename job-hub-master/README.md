# JobHub — 个人安全求职表单与投递助手

本项目基于 [Zheyi-D/job-hub](https://github.com/Zheyi-D/job-hub) 的 MIT 开源版本进行二次开发，主要面向国内校园招聘和企业招聘官网。它保留了 JobHub 的简历资料管理、表单填写与投递追踪思路，并重点增强了本地规则识别、多段教育经历、填写安全边界、投递结果检测和飞书多维表格同步。

扩展只在用户操作后扫描和填写页面；不会自动登录、处理验证码、上传文件、点击“下一步”或提交申请，也不会调用 LLM。最终投递始终由用户本人完成。

## 功能

| Tab | 功能 | 说明 |
|-----|------|------|
| 📝 简历填充 | 阶段一启用 | 规则扫描、脱敏预检、高置信度安全填写、逐项确认、撤销、网站字段映射。 |
| 📋 投递追踪 | 阶段二启用 | 监听用户真实提交、结果检测、信息补全、查重 upsert 与失败队列。 |
| 📊 数据看板 | 阶段二启用 | 从飞书读取投递记录。 |

## 相比原版 JobHub 的主要优化

### 简历字段识别与填写

- 改为纯本地规则引擎，不依赖 AI 或远程字段匹配服务。
- 扩大可识别资料范围，包括现居住地址、户籍地址、籍贯、邮编、身高、体重、英语等级、CET4/CET6 成绩等常见校招字段。
- 支持日期格式适配，可按页面要求填写完整日期、年月以及拆分的年/月控件。
- 原生下拉框按真实候选值匹配；自定义下拉框仅在候选唯一且页面确认选中时填写，找不到对应值则保持为空。
- 用户主动点击单个资料字段时，可填写自动白名单之外的普通字段；密码、验证码、文件上传、提交按钮和声明确认仍保持硬隔离。
- 填写完成后重新检查必填项，并用长时提示列出仍未填写的字段。
- 支持批量填写后的安全撤销；若用户已经修改页面内容，不会强行覆盖或撤销。

### 多段教育经历

- 能识别页面现有教育经历数量，并在定位唯一、安全可验证时自动补充缺少的教育经历卡片。
- 学校、学院、专业、学历、教育类型、入学时间、毕业时间、GPA 和排名可按照第 1/2 条教育经历分别匹配。
- 针对招聘页面常见的四段式就读时间（开始年、开始月、结束年、结束月）进行了适配。
- 修复自定义字段和 `CET4`、`CET6` 被错误识别为经历编号的问题。

### 投递检测与信息补全

- 只监听用户真实的最终提交操作，不代替用户提交。
- 综合成功 URL、成功/失败文字、完成页变化和申请编号判断结果。
- 信号冲突或无法确定时进入“不确定”状态，由用户选择“确认已投递”“投递失败”或暂不处理。
- 投递信息不完整时显示统一补全窗口；用户确认后才进行完整同步，不发送未经确认的部分记录。

### 飞书多维表格同步

- 支持公司、岗位名称、岗位编号、岗位方向、工作地点、官网链接、JD、申请编号、简历版本、投递阶段、结果和时间等字段。
- 官网链接按飞书超链接对象写入，时间字段按时间戳写入。
- 根据公司、岗位编号、岗位名称、工作地点和规范化链接查重，重复投递执行幂等更新，避免反复新增记录。
- 空值默认不覆盖飞书已有内容，也不修改流程记录、备注等人工维护字段。
- 网络或飞书接口失败时进入本地待同步队列，重试仍执行查重。
- 连接检测区分必要字段和可选字段；缺少可选列时自动跳过，不阻止同步。

### 隐私与安全

- 发布版本不预置任何 App ID、App Secret、Base App Token、Table ID 或访问令牌。
- App Secret 只存储在当前浏览器的扩展本地存储中，飞书访问令牌只缓存在会话存储中。
- 不采集 Cookie、密码、验证码、上传文件内容或完整申请表数据。
- 待确认草稿和失败队列不保存 App Secret 或访问令牌。

## AI 功能

阶段一和阶段二均不调用任何 LLM。原项目 AI 模块保留作来源参考，但不在当前 UI 或执行路径中启用。

## 安装

1. 下载本仓库 ZIP 或 `git clone`
2. 打开 Chrome → `chrome://extensions` → 开启「开发者模式」
3. 点击「加载已解压的扩展程序」→ 选择本目录 `job-hub-master`
4. 点击工具栏 JobHub 图标打开侧边栏

## 飞书配置

设置页不预置任何个人飞书配置；使用者需要自行填写 App ID、App Secret、Base App Token 和投递记录 Table ID。目标表需包含设置页列出的字段，其中 `官网链接`为超链接、`工作地点`为文本。飞书 API 自带的 `record_id` 用作记录与关联标识，不需要自建 `rec_id` 文本列。同步只更新白名单字段，不修改流程记录和人工维护字段。

## 技术栈

- **Chrome Extension Manifest V3**
- **纯原生 JS/CSS/HTML** — 零 npm 依赖，零构建工具
- **ES Modules** — service worker 和 side panel
- **Neo-Brutalist 设计风格** — 粗黑边框、硬边缘阴影、零圆角、纯色配色
- **无 LLM 调用** — 字段识别和填写完全在浏览器本地完成；仅用户配置并确认后调用飞书 API
- **chrome.storage** — local 持久化 + session 缓存
