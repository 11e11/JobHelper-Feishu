# JobHelper Feishu — 求职表单填写与投递追踪助手

本项目基于 [Zheyi-D/job-hub](https://github.com/Zheyi-D/job-hub) 的 MIT 开源版本进行二次开发，主要面向国内校园招聘与企业招聘官网。当前可直接加载的扩展源码位于 [`job-hub-master/`](./job-hub-master/)；根目录早期的 TypeScript 原型仅作为历史实现保留。

项目保留了 JobHub 的简历资料管理、表单填写和投递追踪思路，并重点增强了多段教育经历、国内招聘表单识别、安全填写边界、投递结果检测以及飞书多维表格同步。

## 当前功能

| 模块 | 当前能力 |
|---|---|
| 简历填充 | 本地扫描、脱敏预检、高置信度批量填写、单项填写、撤销和站点字段映射 |
| 投递追踪 | 监听用户真实提交、判断投递结果、统一补全投递信息和失败任务重试 |
| 飞书同步 | 字段校验、查重、幂等新增/更新、超链接与时间字段适配 |
| 数据看板 | 读取飞书投递记录并在侧边栏展示 |

## 基于 JobHub 完成的优化

### 1. 国内招聘表单识别

- 使用纯本地规则引擎，不依赖 AI 或远程字段匹配服务。
- 扩展姓名、联系方式、现居住地址、户籍地址、籍贯、身高、体重、英语等级、CET4/CET6 成绩等常见校招字段。
- 支持完整日期、年月输入，以及拆分为开始年、开始月、结束年、结束月的时间控件。
- 填写结束后重新检查页面必填项，并长时间列出仍需用户处理的字段。

### 2. 多段教育经历

- 能识别本科、硕士等多条教育经历，并按页面顺序分别匹配资料。
- 页面只有一条教育经历时，在能够唯一定位并验证结果的站点上安全新增缺少的经历卡片。
- 学校、学院、专业、学历、教育类型、入学时间、毕业时间、GPA 和排名均支持按经历编号匹配。
- 修复自定义教育字段分组错误，以及 `CET4`、`CET6` 被误判为经历编号的问题。

### 3. 下拉框与单项填写

- 原生下拉框按页面真实候选值匹配。
- 自定义下拉框只有在候选唯一且页面能够确认选中状态时才填写；无匹配时保持为空，不猜测答案。
- 学校、专业、学历、教育类型等重复字段会结合所在教育经历定位，而不是只按字段名称匹配。
- 用户主动点击单个资料字段时，可以填写自动白名单外的普通字段；多个同名目标无法区分时仍会停止并提示。

### 4. 投递结果检测与补全

- 只监听用户真实的最终提交操作，不代替用户点击提交。
- 综合成功 URL、成功或失败文字、完成页变化和申请编号判断结果。
- 信号冲突或超时时进入“不确定”状态，由用户确认已投递、投递失败或暂不处理。
- 信息不完整时展示统一补全窗口，用户确认后才整体同步，不发送未经确认的部分记录。

### 5. 飞书多维表格同步

- 支持公司、岗位名称、岗位编号、岗位方向、工作地点、官网链接、JD、申请编号、简历版本、当前阶段、当前结果和投递时间等字段。
- 官网链接按飞书超链接写入，日期时间按时间戳写入。
- 根据公司、岗位编号、岗位名称、工作地点和规范化链接查重；重复同步执行幂等更新。
- 空值不会覆盖飞书已有非空内容，也不会修改流程记录、备注等人工维护字段。
- 网络或飞书错误会进入本地待同步队列，重试时仍然查重。
- 缺少可选列时自动跳过；只要必要字段存在即可同步。

### 6. 安全与隐私

- 不自动登录、不读取 Cookie、不处理验证码、不上传文件，也不触发下一步或最终提交。
- 密码、验证码、银行信息、文件上传、提交控件和声明确认属于不可解除的硬隔离项。
- 阶段一字段识别与填写完全在浏览器本地运行，不调用 LLM。
- 发布代码不预置 App ID、App Secret、Base App Token、Table ID 或访问令牌。
- App Secret 只保存在浏览器扩展本地存储，飞书访问令牌只缓存在会话存储；草稿和失败队列不保存二者。

## 安装

无需构建即可加载当前版本：

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择仓库中的 `job-hub-master` 目录。

## 飞书配置

项目不附带任何个人飞书配置。使用者需要在扩展设置页填写自己的 App ID、App Secret、Base App Token 和投递记录 Table ID，并为飞书自建应用配置对应多维表格权限。

## 开发与测试

```bash
cd job-hub-master
npm install
npm run check
npm test
```

当前自动化测试覆盖字段识别、下拉框安全行为、多段教育经历、撤销、提交隔离、投递状态判断以及飞书字段序列化和幂等逻辑。
